# Safety

- Loopback bind only (`DPLAB_BIND` is the explicit opt-in the container uses); the compose file publishes `127.0.0.1` only (a test pins it). The container runs as a non-root user, read-only, with every capability dropped.
- Host header must be a loopback name; writes must be same-origin.
- Netguard blocks every outbound connection (fetch, socket, DNS, UDP) with a self-test, and a test asserts zero attempts in the server process across the whole API in both modes. The regex worker thread is a separate realm that the main thread's guard does not cover, so it installs its own netguard before it handles a job (a doctor check and a test run its self-test and assert six blocked routes and no real attempt), and it is started with an empty environment.
- **The server cannot open a record.** It seals with a fresh ephemeral X25519 key per record (built with `createPrivateKey` from a PKCS8 prefix plus 32 random bytes, then wiped), HKDF-SHA256 and AES-256-GCM, and keeps only ciphertext and clear metadata. There is no decrypt code in `server/src` (a test greps for it), a JWK carrying `d` is refused as a PublicKey, and tests assert the test private key is in no response and no workspace state. The private key is made in the browser with WebCrypto, held in the page's memory only, never sent, never put in localStorage and never logged; decryption happens in the browser when you open one record. A wrong key, or any altered byte, fails the AES-GCM check. The doctor script proves a real seal-then-open round trip with a throwaway key.
- **Nothing the visitor types is echoed.** A value any built-in detector (every personal-data kind, every secret detector) or any of the visitor's own rules recognises is masked in every response field, hop pane, event, error and label: the engine returns offsets, lengths, rule ids and a masked display copy, never a value. A test types a value of every kind, every secret detector and a pasted-rule match through every endpoint, including the error paths, and asserts the raw value is absent from every field and from the console output. Only the labelled scripted mock credential (`sk-MOCK-...`) is shown, in the story only (rule 4). Detector samples are credential-shaped, so they are built on the server at run time and only two booleans per detector leave it.
- **Pasted regular expressions are user-fed.** The TOML parser is bounded (65536 characters, 50 rules, 2000 characters a string, no recursion). Each regex is checked statically (no nested quantifiers, quantified alternation, backreferences, lookaround, named groups, repeat counts over 100, more than 6 unbounded quantifiers, more than 400 characters) and then only ever compiled and run in a worker thread with a hard time limit (4 seconds) and a 20000 character input cap; a job that runs over is killed by terminating the worker, and tests prove a catastrophic pattern that gets past the static check is terminated in bounded time and the runner keeps working. No `eval`, `Function` or `vm` anywhere (a test greps).
- One bad rule refuses the whole paste: nothing is added and Errors names each refused rule; refusals never echo the pattern.
- The server writes no file (a test greps for write calls). The one home-directory touch is reading the optional shared settings file (`~/Development/.env`, or `STANDALONE_ENV`) with `util.parseEnv`, taking only `DPL_LAB_MODE`: no other key enters the server's environment. A bare `MODE` in it is ignored.
- Input is bounded: bodies 32 KB (400 KB for an evaluation, a stream or a rule paste), a text at most 20000 characters, a stream at most 20 frames of 2000, a record at most `MaxBytes` (65536), workspaces, events (200), records (100) and rules (50) capped, and every value used as an object key is type-checked (`Object.hasOwn`).
- Only `.example` and `.invalid` hosts appear in any shipped text (a doctor check scans the filled story in every vertical). The synthetic personal data in the stories is generated from each kind's checksum at run time and belongs to no one.
- Every product claim is labelled "Ping release claim, UNVERIFIED on our tenant" in the banner of every tab, in presenter mode too. Field names from the console swagger of 2026-10-31 are schema only; the lab says so wherever they appear, and tags each field as a swagger name, a lab reading or lab-invented.
