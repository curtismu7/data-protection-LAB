# data-protection-LAB

Demo-tier standalone app: Ping data-protection release claims (deck slides 35, 50, 53 to 55, release 2026-11-02): AIGuard content inspection with graduated outcomes, your own gitleaks-format rules, personal-data kinds with checksums, Agent Insights, the OWASP Agentic Top 10 as qualified, and prompt logging sealed to a key held only in the browser. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7200). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7200 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from the engine; a doctor check and a test fail on drift). **Live** = the real engine on the visitor's text. Both loopback-only, zero outbound (netguard + a test).
- Core: `guard.js` (inspection, policy, outcomes, stream), `pii.js` (11 lab-written kinds, real checksums, near-miss samples), `secrets.js` (15 lab examples), `toml.js` + `safeRegex.js` + `regexRunner.js`/`regexChild.js` (pasted rules: bounded parser, static check, a CHILD PROCESS killed on timeout, with its own netguard, empty environment and capped heap; per-workspace queues; a rule that times out is quarantined), `rules.js` (whole paste refused on one bad rule), `seal.js` (server SEALS only: ephemeral X25519 + HKDF-SHA256 + AES-256-GCM, a LAB-INVENTED envelope), `promptlog.js`, `insights.js`, `compliance.js`, `owasp.js`, `service.js`, `app.js`. Web: `web/src/seal.js` opens records with WebCrypto in the browser; the private key lives in memory only.
- Rules that bite: the server must never hold or accept a private key (a JWK with `d` is refused; no decrypt code in `server/src`; tests grep for it); build X25519 keys with `createPrivateKey` from a PKCS8 prefix plus 32 random bytes, never `generateKeyPair`; a credential or personal value the visitor types is masked in EVERY response field (a test asserts absence from every endpoint); the lab never ships Ping's lists (23 kinds, 364 detectors, 411 rules): its sets are labelled lab-written; each field is tagged swagger name, lab reading or lab-invented; credential-shaped test values are built at run time and detector samples never leave the server; only `.example`/`.invalid` hosts; ports 7200-7249; the gateway app is always "P1 Privilege Agent App"; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Field names (PIIKinds, the category thresholds, modelAIGuardCustomRule, imodelAIGuardRuleImport, modelPromptLogConfig) come from the console swagger of 2026-10-31, schema only. Everything else is lab-invented and tagged so.
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `DPL_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. No catalog id yet (placeholder D0).
